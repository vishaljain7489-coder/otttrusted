# TRUSTED.SHOP - Premium Digital E-Commerce Website

This website is custom-crafted to match your provided theme (dark cinema aesthetic, obsidian and warm gold accents, frosted glass cards, and instant delivery features) for **OTT Subscriptions**, **E-Books**, and **Educational Videos**.

---

## 🚀 How to Open the Website
Simply double-click `index.html` in this folder to open it in your browser (Google Chrome, Microsoft Edge, Brave, Safari, etc.).
No installation or server setup is required.

---

## 🎨 How to Change Colors (When You Want to Change Theme)
At the very top of `css/style.css`, you will find the **Theme Color System**:

```css
:root {
  --bg-main: #08090d;              /* Background color */
  --accent-gold: #cfa358;          /* Primary button & brand gold */
  --accent-gold-light: #e5be79;    /* Highlight gold */
  --accent-gold-glow: rgba(207, 163, 88, 0.32);
  --text-primary: #ffffff;         /* Main text */
  --accent-green: #25d366;         /* WhatsApp & Verified badge */
}
```

Whenever you want to change colors (e.g., to purple, red, cyan, or emerald), simply change `--accent-gold` to your desired color code!
